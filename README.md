## 为什么选择 AI-LINK？

在传统的软路由与旁路由代理工具中，用户往往深陷于繁琐的配置、节点突然暴毙导致的断网、复杂的内网穿透折腾以及黑盒分流带来的无休止排错。

**AI-LINK 以解决真实用户痛点为核心**，采用现代化技术架构重构 OpenWrt 分流体验：
- **看得见** —— 独创 NEXUS 3D 宇宙星图，每个活跃会话的源 IP、分流策略、延迟与吞吐皆具象为流动光球；
- **分得清** —— 15 组策略独立出口，四阶走向查询彻底告别黑盒分流；
- **断不了** —— 智能看门狗自动保活、内核离线毫秒级拆除黑洞、DNS 自动降级自愈。

## 核心王牌功能：用解决用户问题的方式重塑体验

### 1. 🎯 自动节点池 (Auto Node Pool v2) —— 告别手动挑节点与卡顿掉线

> **用户痛点**：
> - 追剧看 4K 视频、远程会议或在线游戏进行到一半，节点突然死掉，只能停下手头的事登录路由器后台手动切换？
> - 订阅里有上百个节点，一个个测试费时费力，很多标注低延迟的节点实际速度极慢？
> - 网络轻微抖动就触发频繁重连，导致网页报错、会话中断或登录状态丢失？

**AI-LINK 解决方案与核心优势**：
- **毫秒级故障感知与无缝平滑自愈**：后台守护进程基于真实应用流量与轻量化周期探测持续巡检。一旦检测到当前节点宕机或丢包恶化，系统自动在毫秒级平滑切至备用健康节点，TCP 关键业务零感知、不掉线。
- **多维综合测速与动态评分模型**：摈弃单纯 ICMP ping 的虚假数据，采用真实 TCP/TLS 握手延迟、下行吞吐与历史滑动成功率三维打分，剔除伪低延迟死节点。
- **业务目标驱动的专属节点池**：支持按 AI / 视频流媒体 / 游戏 / 下载等不同业务场景建立专属独立节点池；支持「一键按延迟筛选 Top 10」智能建池，将好节点物尽其用。
- **防假死雪崩与并发内存水保护**：历史可用节点具备跨周期记忆，杜绝偶发抖动误判；500+ 节点超大订阅测速自动采用内存水位动态配额与请求限频，确保软路由低配硬件永不 OOM。
- **手动/自动正交解耦**：用户手动锁定的节点享有绝对控制权，即使不可用也严格保态不漂移；动态切换全部收敛于节点池内，绝不干扰用户自定义配置。

### 2. 🛡️ 全域安全防护 (Security Shield) —— 告别 DNS 劫持、泄漏与内网隐私窥探

> **用户痛点**：
> - 运营商劫持 DNS，频繁弹出恶意广告或被诱导重定向至未知网页？
> - 访问特定站点发生 DNS 泄漏，内网设备真实 IP 与访问轨迹暴露无遗？
> - 局域网接入摄像头、NAS、智能家居等敏感设备，担心被公网扫描刺探或恶意挖矿流量潜伏？

**AI-LINK 解决方案与核心优势**：
- **双层深度 DNS 净网防御体系**：在 DNS 解析层（`REFUSED` 拒绝）与网络路由层（`REJECT` 拦截）构建双重滤网，内置 50,000+ 条广告过滤、恶意重定向、隐私追踪与钓鱼规则，在网关入口处直接阻断威胁。
- **Fake-IP 真实地址脱敏与全链路防泄露**：内置高抗阻 Fake-IP 地址池，杜绝任何本地 DNS 查询泄露；提供 Strict / Loose / Off 三档专用 IPv6 防泄漏机制，完美解决旁路由 IPv6 旁路旁逃逸难题。
- **网络医生 (Network Doctor) 8 项并发并发体检**：秒级并发诊断 DNS 归属污染、AAAA 记录异常、IPv6 绕过、DDNS 状态、端口暴露、上游连通性、MTU 匹配与核心应用健康度，发现隐患支持一键自动修复。
- **局域网安全鉴权与内核黑洞熔断**：控制台支持局域网访问鉴权，API 敏感凭据全量脱敏；当后台内核异常退出时，看门狗在 1 秒内自动拆除全部透明代理链与黑洞策略，立即无缝降级为纯净直连，绝不因插件故障瘫痪全屋网络。

### 3. 🏠 加密回家隧道 (HomeLink) —— 告别无公网 IP 与复杂穿透，一键直连家庭内网

> **用户痛点**：
> - 出差、旅游或在办公室，急需访问家中的群晖 NAS 文档、私有云相册或管理智能家居，但宽带根本没有公网 IPv4 地址？
> - 第三方内网穿透限速严重、配置极其繁琐，且隐私数据需要经过第三方服务器中转？
> - 动态 DDNS 经常解析延迟，配置端口转发不仅步骤繁琐还极易将内网服务暴露在公网攻击下？

**AI-LINK 解决方案与核心优势**：
- **前沿高性能加密隧道直连**：内置最新一代 Hysteria2（基于 UDP/QUIC）与 VLESS-Reality 穿透协议，抗弱网抖动能力极强，在无公网 IPv4 的复杂宽带环境下也能实现极速直连。
- **零门槛扫码即连**：无需繁琐的端口映射与复杂配置，在管理面板一键生成回家节点，手机/笔记本扫描二维码或一键复制标准协议链接即可立即导入客户端。
- **三种灵活边界的内网反向分流**：
  - *局域网专用*：仅转发家庭内网网段（192.168.x.x / 10.x.x.x），在外访问家中 NAS 的同时，外部设备访问互联网继续使用当前所在网络；
  - *全量家庭代理*：将外部设备所有流量安全加密导入家中网关，出差在外也能安全享用家庭宽带的稳定连接与全局分流策略；
  - *自定义路由*：支持按需灵活指定访问网段。
- **企业级端到端安全加密**：纯点对点私有加密传输，无任何第三方中转，真正保障家庭核心资产、个人照片与监控数据的绝对隐私安全。

## 快速开始

### 环境要求

- **操作系统**：OpenWrt **23.05+ / 24.10 / ImmortalWrt 25.x**（基于 `fw4` + `nftables`，支持 `opkg` 与 `apk`）
- **CPU 架构**：`x86_64` / `aarch64` / `armv7` / `mipsel` / `riscv64`
- **硬件要求**：至少 32 MB 可用 Flash 存储空间；建议运行内存 ≥ 256 MB

### 一键安装

在路由器终端运行以下安装脚本：

```sh
curl -fsSL https://ai-link-official.pages.dev/install.sh | sh
```

> **说明**：安装脚本会自动识别软路由系统架构、包管理器类型，安全清理可能冲突的历史代理残留，下载并严格核验当前系统适配的离线安装包，安装完毕后自动完成内核运行与端口状态冒烟自检。

### 无损更新

```sh
# 已安装用户可通过终端一键无损检测并安全升级（具备配置快照回滚保护）：
ai-link update --apply

# 或通过在线更新脚本升级：
curl -fsSL https://ai-link-official.pages.dev/upgrade.sh | sh
```

### 状态自检

```sh
ai-link check                   # 快速自检 daemon / core / nft / 端口 / 出口连通性
ai-link status                  # 查看面板与内核当前实时状态
```

安装完成后，在浏览器中打开：`http://<路由器内网IP>:9099` 即可进入 AI-LINK NEXUS 控制台。

```

```

## 安全建议

1. **面板访问凭据**：管理面板默认信任局域网（`require_lan_auth=false`）。**若 9099 端口可能暴露至公网，请务必在「设置」中开启「强制内网登录」并修改初始密码。**
2. **凭据安全脱敏**：前端控制台不向浏览器写入任何持久化令牌 Cookie，所有对外的状态及诊断接口均已实施凭据脱敏。
3. **接口绑定限制**：生产环境中建议将控制台端口绑定至特定内网管理接口，禁止任意未信任网段访问。
