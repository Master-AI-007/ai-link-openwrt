INSTALL & UPGRADE

一行命令，装好或升级

支持 apk（OpenWrt 24.10+ / ImmortalWrt 25.x）与 opkg（iStoreOS / 23.05），自动识别架构并从官方源下载校验。

root@openwrt:~
# 全新安装（自动选架构、校验 MD5）
curl -fsSL https://ai-link-official.pages.dev/install.sh | sh

# 已装用户升级到 2.0.2
ai-link update --apply

# 或走升级脚本
curl -fsSL https://ai-link-official.pages.dev/upgrade.sh | sh

# 装完自检
ai-link check
svc: daemon=1 core=1 nft=1 enabled=1
1

确认是 fw4 + nftables

OpenWrt 23.05 以上默认即是。老版本 fw3 会提示不兼容。

2

执行安装命令

脚本会检测包管理器、架构，清理冲突透明代理插件，安装后做进程与端口健康断言。

3

打开 :9099 面板

导入订阅 → 选分流模式 → 按需微调各组出口，默认已是推荐配置。

4

升级自动回滚

升级失败会回到升级前版本，节点与配置不丢。

安全默认

面板默认信任局域网；若端口可能暴露公网，请在「连接与设置 → 面板安全」开启强制登录并改掉初始密码。首页不发送令牌 Cookie，/api/status 对非回环请求脱敏。
